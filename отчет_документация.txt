══════════════════════════════════════════════════════════════════════════════

1.1 Актуальность темы
──────────────────────
Логистические цепочки поставок (supply chain) являются фундаментом
современной мировой экономики. Ежегодный объём товарооборота в глобальных
логистических сетях превышает $19 триллионов. При этом неэффективность
управления цепочками обходится компаниям в 5–20% выручки.

Казахстан занимает уникальное географическое положение — транзитный хаб
между Европой и Азией по маршрутам Китай–Европа. Логистика составляет
около 7–8% ВВП страны. По данным Всемирного Банка (Logistics Performance
Index 2023), Казахстан набрал 2.74 из 5.0 баллов, что указывает на
значительный потенциал для цифрового улучшения отрасли.

По результатам исследования McKinsey (2024), компании, внедрившие
AI-аналитику в логистику:
  • сократили затраты на 15–25%
  • улучшили показатель OTD на 5–8%
  • снизили складские запасы на 20–30%

В этом контексте разработка инструментов цифровой аналитики цепочек
поставок является актуальной и практически значимой задачей.

1.2 Цель проекта
─────────────────
Разработать интерактивную веб-платформу для визуализации и анализа данных
логистических цепочек поставок с применением современных веб-технологий
и искусственного интеллекта.

1.3 Задачи проекта
───────────────────
1. Исследовать предметную область логистики и ключевые KPI supply chain
2. Спроектировать структуру и пользовательский интерфейс пятистраничного
   веб-сайта
3. Разработать аналитический дашборд с интерактивными графиками
4. Интегрировать AI-ассистента на основе Pollinations AI API
5. Реализовать инструмент расчёта и оптимизации логистических маршрутов
6. Реализовать двуязычную локализацию (русский / казахский)
7. Обеспечить адаптивный дизайн для мобильных и десктопных устройств
8. Опубликовать проект в системе контроля версий GitHub

3.2 Архитектура приложения
────────────────────────────
Приложение построено по принципу многостраничного сайта (MPA — Multi-Page
Application). Каждая страница — самостоятельный HTML-документ, подключающий
общие CSS и JS файлы.

Слои:
  1. Представление (View)    — HTML страницы + CSS стили
  2. Логика (Controller)     — main.js (анимации, чат, расчёты)
  3. Локализация             — i18n.js (переводы, SELECTORS, setLang())
  4. Внешний API             — Pollinations AI (HTTP POST)

Потоки данных:
  • Пользователь → DOM Event → JS-функция → обновление DOM
  • Пользователь → чат → fetch(Pollinations API) → ответ в DOM
  • Скролл → IntersectionObserver → CSS transition (reveal)
  • Кнопка языка → setLang() → перебор SELECTORS → innerHTML/textContent

РАЗДЕЛ 6. СИСТЕМА ЛОКАЛИЗАЦИИ
══════════════════════════════════════════════════════════════════════════════

Файл: i18n.js

Структура:
  const T = { ru: { ... }, kz: { ... } }
  — объект с ~120 ключами перевода для каждого языка

  const SELECTORS = { _all: [...], 'index.html': [...], ... }
  — карта CSS-селекторов для каждой страницы

Принцип работы:
  1. При загрузке страницы читается localStorage.getItem('lang')
  2. Если 'kz' — вызывается setLang('kz'), иначе остаётся русский (default)
  3. setLang() перебирает SELECTORS[page] и заменяет textContent/innerHTML
     каждого найденного элемента на перевод из T[lang]
  4. Для массивов (each: [...]) — перебирает querySelectorAll по индексу
  5. Для placeholder (type:'ph') — заменяет атрибут placeholder
  6. renderStages() — отдельная функция для списка этапов (about.html)
  7. lang-кнопки добавляются динамически в шапку через DOMContentLoaded

Покрытие переводов:
  • Навигация (5 пунктов)
  • Футер (авторы, дисциплина, специальность)
  • Главная: бейдж, заголовок, подзаголовок, статистика, карточки, CTA
  • Аналитика: KPI, вкладки, заголовки графиков, таблица, AI-инсайты
  • AI-инструменты: метки форм, кнопки, заголовки секций
  • О проекте: заголовки разделов, подзаголовки, этапы
  • Контакты: форма, карточки, статус-сообщения

7.1 LogiBot — AI-ассистент
────────────────────────────
API: Pollinations AI (https://text.pollinations.ai/)
Метод: POST
Тело запроса (JSON):
  {
    "model": "openai",
    "messages": [
      { "role": "system", "content": "Ты — эксперт по логистике..." },
      { "role": "user",   "content": "<вопрос пользователя>" }
    ]
  }

Системный промпт включает:
  • Роль: эксперт по логистике и supply chain в Казахстане и СНГ

  • Фокус: практические рекомендации, цифры, конкретные советы
  • Ограничение ответа: до 200 слов

Fallback (при ошибке сети):
  Функция getLocalReply() — шаблонные ответы по ключевым словам
  (маршрут, KPI, запас, затраты, Казахстан и т.д.)

10.2 Практическая ценность
────────────────────────────
Проект демонстрирует применение ИКТ для решения реальных бизнес-задач:
• Визуализация сложных данных делает логистические процессы понятными
  для менеджеров без технической подготовки
• AI-ассистент снижает время на поиск ответов по логистике
• Оптимизатор маршрутов помогает выбрать оптимальный вид транспорта
  с учётом стоимости, времени и экологичности (CO₂)

1. Современные веб-технологии (HTML5/CSS3/JS) позволяют создавать

2. Интеграция бесплатных AI API (Pollinations) делает AI-функции
   доступными для учебных и некоммерческих проектов

3. Тема логистики и supply chain является актуальной для Казахстана,

   аудиторию без дублирования кода
