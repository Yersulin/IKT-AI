ШАГ 1: Главная страница
  → Показать анимированный canvas-фон (летящие точки-узлы сети)
  → Показать анимацию счётчиков (94.7%, 1284 маршрутов, 32+ страны)
  → "Видите, все числа анимируются при загрузке — это Canvas API и

ШАГ 2: Аналитика
  → Открыть страницу analytics.html
  → Показать 4 KPI-карточки сверху
  → Нажать на одну из вкладок (Q4 / Q3 / Q2) — данные меняются
  → Показать графики: "Это Chart.js — линейный, столбчатый, кольцевой"
  → Проскроллить до AI-инсайтов — "Вот AI-анализ: общая тенденция,
     выявленные проблемы, рекомендации и прогноз на Q1 2026"
  → Нажать "Экспорт CSV"

ШАГ 3: AI-инструменты (САМОЕ ВАЖНОЕ)
  → Открыть ai-tools.html
  → В чате написать: "Как снизить затраты на логистику в Казахстане?"
  → Пока идёт ответ: "LogiBot использует Pollinations AI API —
     это бесплатный AI без регистрации и токенов"
  → Показать оптимизатор маршрутов: выбрать Алматы → Москва → Авиационный
  → Нажать "Рассчитать маршрут" — показать результат (расстояние, время,
     стоимость, CO₂)
  → Нажать "Сгенерировать прогноз" в предиктивной аналитике

ШАГ 4: Локализация
  → Нажать кнопку "ҚЗ" в шапке — весь сайт переключается на казахский
  → "Реализована двуязычная локализация: русский и казахский языки,

В: Почему именно тема логистики?
О: "Казахстан — транзитный хаб между Европой и Азией. Логистика составляет
   7–8% ВВП страны. Индекс LPI Казахстана (2.74/5.0) показывает большой
   потенциал для цифровизации. Тема актуальна и практически значима."

В: Данные настоящие или выдуманные?
О: "Данные основаны на реальных источниках: статистика QazStat, отчёты
   КТЖ Экспресс 2024, World Bank LPI, данные IATA. Значения адаптированы
   для демонстрационных целей, но порядок цифр соответствует реальности."

В: Как работает AI-чат?
О: "Мы используем Pollinations AI API — это бесплатный сервис с открытым
   доступом, совместимый с протоколом OpenAI. Отправляем POST-запрос с
   системным промптом о логистике и вопросом пользователя. Если API
   недоступен, есть локальный резервный ответ."

В: Почему не использовали фреймворк (React, Vue)?
О: "Проект учебный — важно показать понимание базовых веб-технологий.
   Чистый JavaScript демонстрирует работу с DOM, событиями, Canvas API,
   fetch-запросами без абстракций фреймворка. Размер кода при этом
   минимален и всё работает без сборки."

В: Что такое OTD, OTIF, Lead Time?
О: "OTD (On-Time Delivery) — доля доставок, выполненных в срок. Наш: 94.7%.
   OTIF (On-Time In Full) — доставлено вовремя и в полном объёме: 91.2%.
   Lead Time — время от размещения заказа до получения товара: 4.2 дня."

В: Как реализована локализация?
О: "В файле i18n.js хранится объект T с ключами для русского и казахского.
   При нажатии ҚЗ/РУ функция setLang() перебирает CSS-селекторы и заменяет
   текст. Выбор сохраняется в localStorage и восстанавливается при следующем
   визите."

В: Адаптивен ли сайт для мобильных?
О: "Да. Используем CSS Flexbox и Grid с auto-fit, медиазапросы с
   breakpoints 768px и 480px. Хедер сворачивается, сетки меняются
   с 3-х колонок на 1. Проверяли в браузере на разных размерах."

В: Откуда данные для оптимизатора маршрутов?
О: "Расстояния между казахстанскими и соседними городами взяты из реальной
   географии. Стоимость и CO₂ рассчитываются по тарифным коэффициентам
   для каждого вида транспорта (авто, ж/д, авиа, морской)."

В: Что такое Canvas API?
О: "Canvas API — это HTML5-элемент для рисования через JavaScript.
   Мы создаём анимированную сеть из точек (узлов) и линий (маршрутов)
   на главной странице. Каждый кадр перерисовывается через requestAnimationFrame
   с плавным движением частиц."
